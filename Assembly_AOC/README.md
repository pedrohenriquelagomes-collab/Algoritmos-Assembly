# Assembly AOC

## Lista 1 — Assembly MIPS

Lista composta por 12 exercícios práticos desenvolvidos utilizando o simulador MARS.

### Conteúdos abordados

- Operações aritméticas
- Estruturas condicionais
- Laços de repetição
- Validação de dados
- Comparação de valores
- Identificação de valores mínimos e máximos

### Descrição

Exercícios envolvendo cálculos de áreas e salários, operações com números inteiros, divisão, contagem por intervalos e análise de alturas.
